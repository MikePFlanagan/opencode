# UPTRIS Design Manifesto (Excerpt)

1. **Everything Is Bricks** — every object is explainable as an arrangement of bricks.
2. **Nothing Simply Disappears** — break → scatter → reorganize → become something else.
3. **Never Change Games** — transform the current game; no black-screen genre swaps.
4. **The Brick Must Matter** — bricks affect destruction, physics, puzzles, progression.
5. **Strange Physics Are Features** — a square pinball that usually rolls until a corner catches.
6. **Gameplay First** — lore supports transformations; mythology stays mysterious.

Full roadmap lives with the project owner’s Master Game Design document.
